# 🧠 Gen AI & LangChain

A hands-on repository for learning and building **Generative AI applications with Python and LangChain**.

This repository contains practical examples covering LLMs, prompts, chains, embeddings, vector-based similarity search, output parsers, structured outputs, RAG components, and other core building blocks used in modern GenAI applications.

---

## 🚀 What You'll Learn

- 🤖 Working with **LLMs and Chat Models**
- 💬 Designing effective **Prompts**
- 🔗 Building **LangChain Chains**
- 🧩 Understanding **Runnables**
- 🧠 Generating and working with **Embeddings**
- 🔎 Performing **Similarity Search**
- 📄 Loading and processing documents
- 📚 Understanding **RAG components**
- 📝 Parsing LLM outputs
- 📦 Working with **Structured Outputs**
- 🛠️ Building reusable GenAI components
